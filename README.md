# מתרגם קומיקס 📖➡️🇮🇱

סקריפט לספארי באייפון (עובד גם במחשב) שמתרגם לעברית את בועות הדיבור בקומיקס ובוובטון,
וכותב את התרגום ישירות על התמונה באתר.

## איך זה עובד
- לוחצים על הכפתור הסגול **"תרגם"** בפינת המסך (פעם אחת לכל אתר – הוא זוכר).
- תוך כדי גלילה, כל תמונה של קומיקס נשלחת ל-**Gemini** של Google, שמוצא את הבועות ומתרגם אותן.
- התרגום מופיע בתוך בועה לבנה מעל הטקסט המקורי. **נגיעה בבועה** מציגה שוב את המקור.
- תמונות שכבר תורגמו נשמרות, כך שחזרה לפרק לא עולה שוב כסף.

## עובד בכל אתר
הסקריפט רץ בכל האתרים ומזהה לבד את תמונות הקומיקס, בכל צורה שהאתר מציג אותן:
- וובטון ארוך בגלילה (Webtoon, Tapas ודומים). רצועות ארוכות נחתכות לחלקים.
- קורא עמוד-עמוד שבו מדפדפים בין עמודים. כל עמוד חדש מתורגם, וחזרה לעמוד קודם נטענת מהשמירה.
- קומיקס שמצויר על Canvas או מוצג כתמונת רקע.
- תמונות שנטענות רק כשמגיעים אליהן בגלילה, וקומיקס שנפתח בתוך מסגרת (iframe).

תמונות קטנות, כמו אייקונים ותמונות פרופיל, לא מתורגמות.
צריך ללחוץ "תרגם" פעם אחת בכל אתר קומיקס חדש, כדי שהסקריפט לא ישלם על תרגום של תמונות באתרים אחרים, כמו אתרי חדשות.

## התקנה באייפון (פעם אחת)

### 1. מפתח API של Gemini
1. נכנסים ל-[aistudio.google.com/apikey](https://aistudio.google.com/apikey) עם חשבון Google.
2. לוחצים **Create API key** ובוחרים את הפרויקט שמחובר לחשבון הבילינג שלך.
3. מעתיקים את המפתח (מתחיל ב-`AQ.`; מפתחות ישנים מתחילים ב-`AIza`, גם הם עובדים).

> רוצה להשתמש ב-Claude במקום? מדביקים מפתח של Anthropic (מתחיל ב-`sk-ant-`), והסקריפט יעבור אליו לבד.

### 2. האפליקציה Userscripts
1. מורידים מה-App Store את האפליקציה החינמית **Userscripts** (של Justin Wasack).
2. פותחים אותה פעם אחת ובוחרים תיקייה לסקריפטים (למשל "On My iPhone").
3. **הגדרות ← אפליקציות ← Safari ← הרחבות ← Userscripts**: מפעילים, ובהרשאות בוחרים **"אפשר" לכל האתרים**.

### 3. התקנת הסקריפט
**אם הריפו ציבורי:** פותחים בספארי את הקישור
`https://raw.githubusercontent.com/hilaf2331-rgb/translator/main/comic-translator.user.js`,
לוחצים על סמל ההרחבות בשורת הכתובת ← **Userscripts** ← **Install**.

**אם הריפו פרטי:** מורידים את הקובץ `comic-translator.user.js` מ-GitHub
(פותחים את הקובץ ← `⋯` ← Download), ובאפליקציית **קבצים** מעבירים אותו לתיקייה שבחרת בשלב 2.

### 4. שימוש
נכנסים לאתר הקומיקס, לוחצים **"תרגם"**, מדביקים את המפתח בפעם הראשונה, וזהו.
כפתור ⚙ מאפשר להחליף מפתח, לנקות את התרגומים השמורים, להסתיר את הכפתורים, להגדיר שרת עזר (4) ולבחור פונט (5).

### איך התרגום נראה
- **פונט:** פונט עברי בסגנון קומיקס, כברירת מחדל **גברת לוין** (כתב יד). ב-⚙ ← 5 אפשר לבחור מתוך 6 פונטים.
- **גודל:** התרגום מותאם לגודל של הכתב המקורי, ומוקטן רק כשהעברית ארוכה יותר.
- **צבעים:** הרקע והטקסט לוקחים את הצבע של הבועה עצמה, כך שבועות צבעוניות ותיבות כהות נשארות באותו צבע.

### קללות ותוכן למבוגרים
- **כברירת מחדל התרגום נאמן:** קללות וסלנג מתורגמים באותה עוצמה כמו במקור, בלי צנזורה. ב-⚙ ← 6 אפשר לעבור לתרגום מעודן, ובחזרה.
- **מסננים:** המסננים של הטרדה, שנאה ותוכן מסוכן מוגדרים לא לחסום, כדי שקללות ואלימות יתורגמו. מסנן התוכן המיני נשאר בהגדרת ברירת המחדל של Google, כך שסצנות מפורשות פשוט לא יתורגמו ויופיעו כ"נחסם".
- **תמונה חסומה:** אם Google חוסם תמונה או חלק ממנה, מופיעה על התמונה הודעה "נחסם על ידי Google". היא לא נשמרת, כך שאפשר לנסות שוב אחר כך.

### איפה המפתח נשמר?
- המפתח נשמר **רק באייפון שלך**, באחסון הפרטי של האפליקציה Userscripts. הוא לא נמצא בקוד, לא ב-GitHub, והאתרים שאת גולשת בהם לא יכולים לקרוא אותו.
- הוא נשלח רק לשרת של Google, יחד עם התמונה שצריך לתרגם.
- כדי להגן על החשבון, כדאי להגביל את המפתח ב-[Google Cloud Console ← APIs & Services ← Credentials](https://console.cloud.google.com/apis/credentials) לשימוש ב-**Generative Language API** בלבד.
- כדאי גם להגדיר **התראת תקציב** (Billing ← Budgets & alerts), למשל על 10$ בחודש.
- אם נראה לך שהמפתח דלף, מוחקים אותו ב-AI Studio ויוצרים חדש.

## שרת עזר לתמונות (רק לאתרים שחוסמים)
יש אתרים ששרת התמונות שלהם מסרב לתת את התמונות לכל מי שהוא לא הדף עצמו. ספארי לא מאפשר לתוספים לעקוף את זה.
באתרים כאלה תופיע שגיאה עם המילים **"שרת עזר"**. הפתרון הוא שרת קטן משלך ב-Cloudflare שמוריד את התמונות בשביל הסקריפט.
השרת **חינמי לגמרי**, בלי כרטיס אשראי, ומגדירים אותו פעם אחת. אחרי זה הוא עובד בכל האתרים החוסמים.

1. **חשבון:** נכנסים ל-[dash.cloudflare.com/sign-up](https://dash.cloudflare.com/sign-up), נרשמים בחינם ומאשרים את המייל.
2. **יצירת השרת:** בתפריט בוחרים **Workers & Pages** ← **Create** ← **Start with Hello World!**.
   נותנים לו את השם `comic-helper` ולוחצים **Deploy**. בשלב הזה מופיע "Hello World", וזה בסדר.
3. **חיבור לקוד ב-GitHub:** באייפון העורך של Cloudflare לא מקבל הדבקה, אז Cloudflare לוקח את הקוד ישירות מהריפו.
   - בשרת `comic-helper` נכנסים ל-**Settings** ← **Build** ← **Connect** ← **GitHub**.
   - ב-GitHub מאשרים גישה, ועדיף לבחור **Only select repositories** ← `translator`.
   - בוחרים את הריפו **translator** ואת הענף **main**, ולוחצים **Connect**.
   - הבנייה מתחילה כשמשהו משתנה בענף `main`. אפשר לראות אותה בלשונית **Deployments**.
4. **בדיקה:** בדף הראשי של השרת מופיעה הכתובת שלו (משהו כמו `comic-helper.השם-שלך.workers.dev`). פותחים אותה בספארי עם `https://` בהתחלה.
   אמור להופיע: `Comic Translator image helper is running ✓`
5. **חיבור לסקריפט:** באתר הקומיקס לוחצים ⚙, כותבים **4**, מדביקים את הכתובת ולוחצים אישור.

**פרטיות:** השרת רק מעביר תמונות ולא שומר כלום. הוא לא מקבל את מפתח ה-API ולא יכול לראות אותו.
**עלות:** בתוכנית החינמית אפשר 100,000 תמונות ביום. אם עוברים את המגבלה, השרת פשוט מפסיק לעבוד עד מחר. אין חיוב.

## במחשב
מתקינים את התוסף **Tampermonkey** לכרום, ופותחים את אותו קישור של הקובץ.

## עלות
הסקריפט משתמש ב-`gemini-3.8-flash`, מודל מהיר וזול יחסית. התשלום לפי מספר התמונות, והמחיר העדכני מופיע ב-[דף התמחור של Gemini](https://ai.google.dev/gemini-api/docs/pricing).
כדי לדעת כמה פרק עולה בפועל, בודקים ב-Google Cloud Console ← Billing אחרי שקוראים פרק אחד.
הסקריפט שולח את כל תמונות הפרק, גם כאלה שאין בהן טקסט. תמונות שכבר תורגמו לא נשלחות שוב.

## שינוי הגדרות
בראש הקובץ `comic-translator.user.js` אפשר לשנות:
- `GEMINI_MODEL` – למשל `'gemini-3.1-pro-preview'` לתרגום מדויק יותר (ויקר יותר), או `'gemini-3.5-flash-lite'` לזול יותר
- `SOURCE_LANG` – שפת המקור (למשל `'Korean'` או `'Japanese'`)
- `TRANSLATE_SFX` – `true` כדי לתרגם גם אפקטים קוליים
- `MIN_IMG_WIDTH` / `MIN_IMG_HEIGHT` – מתחת לגודל הזה תמונות לא מתורגמות

## בעיות נפוצות
- **"שגיאה: image HTTP 403 … שרת עזר"** – האתר חוסם הורדת תמונות. צריך להגדיר שרת עזר (ההוראות למעלה).
- **"האתר נועל את התמונה"** – האתר מצייר את הקומיקס בצורה שאי אפשר לקרוא. זה נדיר.
- **הכפתור לא מופיע** – צריך לוודא ש-Userscripts מקבל הרשאה לאתר (סמל ההרחבות ← Userscripts).
- **בועה במקום הלא נכון** – לפעמים קורה. נגיעה בבועה מסתירה אותה.
