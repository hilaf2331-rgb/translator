# מתרגם קומיקס 📖➡️🇮🇱

סקריפט לספארי באייפון (עובד גם במחשב) שמתרגם לעברית את בועות הדיבור בקומיקס ובוובטון,
וכותב את התרגום ישירות על התמונה באתר.

## איך זה עובד
- לוחצים על הכפתור הסגול **"תרגם"** בפינת המסך (פעם אחת לכל אתר – הוא זוכר).
- תוך כדי גלילה, כל תמונה של קומיקס נשלחת ל-**Gemini** של Google, שמוצא את הבועות ומתרגם אותן.
- התרגום מופיע בתוך בועה לבנה מעל הטקסט המקורי. **נגיעה בבועה** מציגה שוב את המקור.
- תמונות שכבר תורגמו נשמרות, כך שחזרה לפרק לא עולה שוב כסף.

## עובד בכל אתר
הסקריפט רץ בכל האתרים ומזהה לבד את תמונות הקומיקס, בכל צורה שהאתר מציג אותן:
- וובטון ארוך בגלילה (Webtoon, Tapas ודומים). רצועות ארוכות נחתכות לחלקים.
- קורא עמוד-עמוד שבו מדפדפים בין עמודים. כל עמוד חדש מתורגם, וחזרה לעמוד קודם נטענת מהשמירה.
- קומיקס שמצויר על Canvas או מוצג כתמונת רקע.
- תמונות שנטענות רק כשמגיעים אליהן בגלילה, וקומיקס שנפתח בתוך מסגרת (iframe).

תמונות קטנות, כמו אייקונים ותמונות פרופיל, לא מתורגמות.
צריך ללחוץ "תרגם" פעם אחת בכל אתר קומיקס חדש, כדי שהסקריפט לא ישלם על תרגום של תמונות באתרים אחרים, כמו אתרי חדשות.

## התקנה באייפון (פעם אחת)

### 1. מפתח API של Gemini
1. נכנסים ל-[aistudio.google.com/apikey](https://aistudio.google.com/apikey) עם חשבון Google.
2. לוחצים **Create API key** ובוחרים את הפרויקט שמחובר לחשבון הבילינג שלך.
3. מעתיקים את המפתח (מתחיל ב-`AIza`).

> רוצה להשתמש ב-Claude במקום? מדביקים מפתח של Anthropic (מתחיל ב-`sk-ant-`), והסקריפט יעבור אליו לבד.

### 2. האפליקציה Userscripts
1. מורידים מה-App Store את האפליקציה החינמית **Userscripts** (של Justin Wasack).
2. פותחים אותה פעם אחת ובוחרים תיקייה לסקריפטים (למשל "On My iPhone").
3. **הגדרות ← אפליקציות ← Safari ← הרחבות ← Userscripts**: מפעילים, ובהרשאות בוחרים **"אפשר" לכל האתרים**.

### 3. התקנת הסקריפט
**אם הריפו ציבורי:** פותחים בספארי את הקישור
`https://raw.githubusercontent.com/hilaf2331-rgb/translator/main/comic-translator.user.js`,
לוחצים על סמל ההרחבות בשורת הכתובת ← **Userscripts** ← **Install**.

**אם הריפו פרטי:** מורידים את הקובץ `comic-translator.user.js` מ-GitHub
(פותחים את הקובץ ← `⋯` ← Download), ובאפליקציית **קבצים** מעבירים אותו לתיקייה שבחרת בשלב 2.

### 4. שימוש
נכנסים לאתר הקומיקס, לוחצים **"תרגם"**, מדביקים את המפתח בפעם הראשונה, וזהו.
כפתור ⚙ מאפשר להחליף מפתח, לנקות את התרגומים השמורים או להסתיר את הכפתורים.

## במחשב
מתקינים את התוסף **Tampermonkey** לכרום, ופותחים את אותו קישור של הקובץ.

## עלות
הסקריפט משתמש ב-`gemini-3.8-flash`, מודל מהיר וזול יחסית. התשלום לפי מספר התמונות, והמחיר העדכני מופיע ב-[דף התמחור של Gemini](https://ai.google.dev/gemini-api/docs/pricing).
כדי לדעת כמה פרק עולה בפועל, בודקים ב-Google Cloud Console ← Billing אחרי שקוראים פרק אחד.
הסקריפט שולח את כל תמונות הפרק, גם כאלה שאין בהן טקסט. תמונות שכבר תורגמו לא נשלחות שוב.

## שינוי הגדרות
בראש הקובץ `comic-translator.user.js` אפשר לשנות:
- `GEMINI_MODEL` – למשל `'gemini-3.1-pro-preview'` לתרגום מדויק יותר (ויקר יותר), או `'gemini-3.5-flash-lite'` לזול יותר
- `SOURCE_LANG` – שפת המקור (למשל `'Korean'` או `'Japanese'`)
- `TRANSLATE_SFX` – `true` כדי לתרגם גם אפקטים קוליים
- `MIN_IMG_WIDTH` / `MIN_IMG_HEIGHT` – מתחת לגודל הזה תמונות לא מתורגמות

## בעיות נפוצות
- **"שגיאה: image HTTP 403"** או **"האתר נועל את התמונה"** – האתר חוסם גישה לתמונות. זה נדיר; ספרי לי באיזה אתר זה קורה ואתאים את הסקריפט.
- **הכפתור לא מופיע** – צריך לוודא ש-Userscripts מקבל הרשאה לאתר (סמל ההרחבות ← Userscripts).
- **בועה במקום הלא נכון** – לפעמים קורה. נגיעה בבועה מסתירה אותה.
