# מתרגם קומיקס 📖➡️🇮🇱

סקריפט לספארי באייפון (ולפיירפוקס באנדרואיד) שמתרגם לעברית את בועות הדיבור בקומיקס, במנגה ובוובטון, מאנגלית, קוריאנית, יפנית או סינית.
התרגום נכתב **ישירות על התמונה באתר**, בפונט של קומיקס ובצבעים של הבועה. הוא עובד גם במחשב.

- עובד בכל אתר קומיקס: וובטון בגלילה, קורא עמוד-עמוד, קומיקס על Canvas או כתמונת רקע.
- מתרגם תוך כדי גלילה, עוד לפני שמגיעים לתמונה.
- נגיעה בבועה מציגה את המקור באנגלית.
- תמונות שכבר תורגמו נשמרות, כך שחזרה לפרק לא עולה שוב כסף.

> 📄 **מדריך התקנה מפורט בעברית (PDF, עם איורים):** [guide-he.pdf](guide-he.pdf)

> ⚠️ **חשוב לדעת לפני שמתחילים**
> - **עלות:** כל משתמש צריך **מפתח API משלו** של Google Gemini, והוא משלם בעצמו על התרגומים שלו. פרטים ב[עלות](#עלות).
> - **אחריות:** הסקריפט ניתן כמו שהוא, בלי אחריות. כל אחד משתמש בו על אחריותו, ובהתאם לתנאי השימוש של Google ושל האתרים שהוא קורא בהם.
> - **שרת עזר:** אם צריך שרת עזר, כל אחד מקים **שרת משלו**. לא משתמשים בשרת של מישהו אחר.

בכרום במחשב צריך להפעיל גם **Allow User Scripts** בפרטי התוסף Tampermonkey (`chrome://extensions`).

## התקנה באייפון (פעם אחת, בערך 10 דקות)

### שלב 1: מפתח API של Gemini
1. נכנסים ל-[aistudio.google.com/apikey](https://aistudio.google.com/apikey) עם חשבון Google.
2. לוחצים **Create API key**. אם מתבקשים, מחברים חשבון בילינג (כרטיס אשראי) לפרויקט.
3. מעתיקים את המפתח. הוא מתחיל ב-`AQ.` (במפתחות ישנים, ב-`AIza`).
4. **מומלץ מאוד, כדי לשמור על החשבון:** ב-[Google Cloud Console ← Credentials](https://console.cloud.google.com/apis/credentials):
   - לוחצים על המפתח ← **API restrictions** ← מסמנים רק **Gemini API** ← **Save**.
   - ב-[AI Studio](https://aistudio.google.com) ← **Billing / Spend**: **לכבות Auto-reload** (טעינה אוטומטית של קרדיט), אחרת Google גובים שוב ושוב ₪50 בלי לשאול.
   - ב-[AI Studio](https://aistudio.google.com) ← **Spend** ← **Monthly spend cap** (העיפרון ✏️) קובעים תקרה, למשל ₪50. כשמגיעים אליה, התרגום נעצר עד החודש הבא.

> ⚠️ **צריך לחבר כרטיס אשראי:** בלי בילינג, Google נותנים רק כ-20 תמונות ביום.

### שלב 2: האפליקציה Userscripts
1. מורידים מה-App Store את האפליקציה החינמית **Userscripts** (של Justin Wasack).
2. פותחים אותה ← **Set Userscripts Directory** ← **On My iPhone** ← יוצרים תיקייה בשם `Userscripts` ← **Open**.
3. **הגדרות ← אפליקציות ← Safari ← הרחבות ← Userscripts**: מפעילים, ובהרשאות בוחרים **"אפשר" לכל האתרים**.

### שלב 3: התקנת הסקריפט
1. פותחים בספארי את הקישור:
   **https://raw.githubusercontent.com/hilaf2331-rgb/translator/main/comic-translator.user.js**
2. לוחצים על סמל ההרחבות 🧩 בשורת הכתובת ← **Userscripts** ← **Install**.

### שלב 4: קוראים!
1. נכנסים לאתר הקומיקס. בפעם הראשונה: סמל ההרחבות ← **Userscripts** ← לוודא שהסקריפט מופיע **בלבן**, כלומר פעיל.
2. לוחצים על הכפתור הסגול **"תרגם"** למטה. אפשר לגרור אותו לכל מקום במסך.
3. בפעם הראשונה בלבד, מדביקים את מפתח ה-API.
4. גוללים, והתרגומים מופיעים 🎉

כל אתר צריך "תרגם" פעם אחת, והסקריפט זוכר אותו. כך הוא לא מתרגם תמונות באתרים שאינם קומיקס.

### עדכונים
כשיוצאת גרסה חדשה מופיע ליד "תרגם" **כפתור ורוד** "עדכון ⬇". לוחצים עליו ← 🧩 ← Userscripts ← **Install**, ומרעננים. המפתח וההגדרות נשמרים. אפשר לבדוק עכשיו דרך ⚙ ← 12, ואת הגרסה הנוכחית רואים למעלה בתפריט ⚙.
אחרי עדכון של GitHub, לפעמים לוקח עד 5 דקות עד שהגרסה החדשה זמינה.

## קללות ותוכן למבוגרים
- **קללות:** כברירת מחדל, קללות וסלנג מתורגמים **באותה עוצמה כמו במקור**. ב-⚙ ← 6 אפשר לעבור לתרגום מעודן.
- **מסננים:** קללות, עלבונות ואלימות לא מסוננים. **תוכן מיני** נשאר על המסנן הרגיל של Google, כך שסצנות מפורשות פשוט לא יתורגמו ויסומנו "נחסם על ידי Google". ב-⚙ ← 10 אפשר לעבור למסנן **מקל**, שחוסם רק תוכן מפורש בוודאות גבוהה. זו הגדרה רשמית של Google.
- **חסימות קבועות:** יש תוכן ש-Google חוסמים תמיד ואי אפשר לשנות את זה.

## איפה המפתח נשמר? 🔒
- **רק באייפון שלך**, באחסון הפרטי של האפליקציה Userscripts.
- הוא לא נמצא בקוד ולא ב-GitHub, והאתרים שאת/ה גולש/ת בהם לא יכולים לקרוא אותו.
- הוא נשלח **רק** לשרת של Google, יחד עם התמונה לתרגום.
- הקוד פתוח, וכל אחד יכול לבדוק את זה.
- **אם נראה שהמפתח דלף:** מוחקים אותו ב-AI Studio ויוצרים חדש.

## שרת עזר לתמונות (רק אם מופיעה שגיאה עם "שרת עזר")
יש אתרים ששרת התמונות שלהם מסרב לתת את התמונות לכל מי שהוא לא הדף עצמו, וספארי לא מאפשר לתוספים לעקוף את זה.
הפתרון הוא שרת קטן **משלך** ב-Cloudflare שמוריד את התמונות בשביל הסקריפט.
השרת **חינמי**, בלי כרטיס אשראי, עד 100,000 תמונות ביום. הוא רק מעביר תמונות: לא שומר כלום ולא רואה את המפתח.

**הדרך הקלה (צריך חשבון GitHub):**

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/hilaf2331-rgb/translator)

לוחצים על הכפתור, נכנסים או נרשמים ל-Cloudflare ול-GitHub, ולוחצים **Deploy**. Cloudflare יעתיק את הקוד לחשבון שלך ויקים את השרת.

**הדרך הידנית:**
1. נרשמים ב-[dash.cloudflare.com/sign-up](https://dash.cloudflare.com/sign-up).
2. יוצרים **fork** לריפו הזה ב-GitHub: כפתור **Fork** בדף הריפו.
3. ב-Cloudflare: **Workers & Pages** ← **Create** ← **Start with Hello World!** ← בשם `comic-helper` ← **Deploy**.
4. בשרת: **Settings** ← **Build** ← **Connect** ← **GitHub** ← בוחרים את ה-fork שלך, ענף `main` ← **Connect**.
5. ב-**Deployments** מחכים לבנייה, ואם צריך עושים שינוי קטן ב-fork כדי להפעיל אותה.

**בסוף, בשתי הדרכים:**
- פותחים בספארי את הכתובת של השרת (`https://comic-helper.השם-שלך.workers.dev`). צריך להופיע:
  `Comic Translator image helper is running ✓`
- באתר הקומיקס: ⚙ ← **4** ← מדביקים את הכתובת.

> אל תפרסמו את כתובת השרת שלכם: כל מי שיודע אותה יכול להשתמש בו.

## עלות
- **Gemini:** הסקריפט משתמש ב-`gemini-3.8-flash`, מודל מהיר וזול יחסית. משלמים לפי מספר התמונות, והמחיר העדכני מופיע ב-[דף התמחור של Gemini](https://ai.google.dev/gemini-api/docs/pricing).
- **כמה זה עולה בפועל:** בערך **חצי שקל לפרק** (נמדד על פרק של כ-80 תמונות). רואים את ההוצאה ב-[AI Studio](https://aistudio.google.com) ← Spend, ואת כמות התמונות ב-⚙ ← 13.
- **להוזיל:** ⚙ ← 7 מפעיל **מצב חסכוני**, בערך חצי מחיר ברוב המקרים. אפשר להשוות את האיכות ולכבות אם לא אוהבים.
- **שרת העזר:** חינמי.

## אנדרואיד
כרום באנדרואיד לא תומך בתוספים, אז משתמשים ב**פיירפוקס**:
1. מתקינים **Firefox** מ-Google Play.
2. בפיירפוקס: ⋮ ← **תוספות** ← **מנהל התוספות** ← **Tampermonkey** ← **הוספה**.
3. פותחים בפיירפוקס את קישור הסקריפט (שלב 3 למעלה) ולוחצים **Install**.
4. קוראים בפיירפוקס: לוחצים **"תרגם"** ומדביקים את המפתח. העדכונים מגיעים לבד.

## במחשב
מתקינים את התוסף **Tampermonkey** (בכרום, באדג' או בפיירפוקס), ופותחים את אותו קישור של הסקריפט.

## למתקדמים
בראש הקובץ `comic-translator.user.js` אפשר לשנות:
- `GEMINI_MODEL`: למשל `'gemini-3.1-pro-preview'` (מדויק ויקר יותר) או `'gemini-3.5-flash-lite'` (זול יותר).
- `TRANSLATE_SFX`: `true` כדי לתרגם גם אפקטים קוליים.
- `MIN_IMG_WIDTH` / `MIN_IMG_HEIGHT`: תמונות קטנות מזה לא מתורגמות.

אפשר להשתמש גם ב-Claude במקום Gemini: מדביקים מפתח של Anthropic (מתחיל ב-`sk-ant-`), והסקריפט עובר אליו לבד.
