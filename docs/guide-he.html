שלב 1: מפתח של Gemini (המנוע שמתרגם)

את התרגום עושה Gemini, הבינה המלאכותית של Google. כדי להשתמש בו צריך "מפתח API": קוד אישי שאומר ל-Google שזה את ושהתשלום עלייך. המפתח הוא כמו סיסמה: לא משתפים אותו עם אף אחד.

1
פותחים בספארי את הכתובת:
https://aistudio.google.com/apikey
ונכנסים עם חשבון ה-Google שלך. אם שואלים אם לאשר תנאים, מאשרים.
2
לוחצים על הכפתור Create API key.
אם שואלים לאיזה פרויקט, בוחרים את מה שמוצע או יוצרים פרויקט חדש. השם לא משנה.
3
מחברים אמצעי תשלום. ליד המפתח או בתפריט יופיע כפתור כמו Set up billing או Billing. לוחצים עליו, ממלאים פרטים ומוסיפים כרטיס אשראי.
💡 המסכים של Google משתנים מדי פעם, אז הכפתורים יכולים להיראות קצת אחרת. מחפשים את המילים Billing או תשלום.
4
מעתיקים את המפתח: לוחצים על סמל ההעתקה ליד המפתח. הוא מתחיל ב-AQ. (במפתחות ישנים, ב-AIza).
כדאי לשמור אותו במקום בטוח, למשל בפתקים עם נעילה או באפליקציית הסיסמאות.

שלב 2: להגן על המפתח ועל הכסף (5 דקות, מאוד מומלץ)

שני דברים קטנים שמבטיחים שגם אם המפתח ידלוף, לא יקרה שום דבר רציני.

א. להגביל את המפתח ל-Gemini בלבד

1
פותחים:
https://console.cloud.google.com/apis/credentials
2
לוחצים על שם המפתח ברשימה.
3
בחלק API restrictions פותחים את הרשימה ומסמנים רק את Gemini API. לוחצים OK.
4
בחלק Application restrictions משאירים על None. זה תקין, האפשרויות האחרות לא מתאימות לכלי הזה.
5
גוללים למטה ולוחצים Save. לוקח עד 5 דקות עד שזה נכנס לתוקף.

ב. התראה על הוצאות

1
פותחים:
https://console.cloud.google.com/billing
ובוחרים את חשבון התשלום שלך.
2
בתפריט: Budgets & alerts ← Create budget.
3
כותבים סכום, למשל 30 ₪ לחודש, ומשאירים את ההתראות שמוצעות (50%, 90%, 100%). שומרים.
✅ עכשיו תקבלי מייל אם ההוצאה מתקרבת לסכום. שימי לב: זו התראה, לא חסימה. היא לא עוצרת את השימוש, רק מודיעה.

שלב 3: האפליקציה Userscripts

Userscripts היא אפליקציה חינמית שמוסיפה לספארי "תוספים קטנים". המתרגם הוא תוסף כזה.

1
פותחים את App Store, מחפשים Userscripts ומורידים את האפליקציה של Justin Wasack. היא חינמית.
2
פותחים את האפליקציה Userscripts. לוחצים Set Userscripts Directory, בוחרים On My iPhone (בעברית: "בטלפון שלי"), יוצרים תיקייה חדשה בשם Userscripts, נכנסים אליה ולוחצים Open.
3
מפעילים את התוסף בספארי: פותחים את אפליקציית הגדרות, ואז:
הגדרות←אפליקציות←Safari←הרחבות←Userscripts
מדליקים את המתג, ובהרשאות בוחרים "כל אתרי האינטרנט" ← "אפשר".
💡 בגרסאות ישנות של iOS אין "אפליקציות": הולכים ישר ל-הגדרות←Safari←הרחבות.

שלב 7: אם מופיעה שגיאה עם "שרת עזר"

רוב האנשים לא צריכים את השלב הזה. הוא רלוונטי רק אם על התמונות מופיעה שגיאה כמו:

image HTTP 403 (…) — האתר חוסם הורדת תמונות. הפתרון: שרת עזר

למה זה קורה: יש אתרים שלא מרשים להוריד את התמונות שלהם לאף אחד חוץ מהדף עצמו, וספארי לא נותן לתוספים לעקוף את זה. הפתרון הוא שרת קטן משלך ב-Cloudflare שמוריד את התמונות בשביל המתרגם. השרת חינמי לגמרי (עד 100,000 תמונות ביום, בלי כרטיס אשראי), מעביר רק תמונות ולא רואה את המפתח.

⚠️ השלב הזה הכי טכני במדריך. צריך גם חשבון GitHub (חינמי). אם נתקעים, אפשר לשלוח לי הודעה.
1
חשבון GitHub: נרשמים בחינם ב-github.com/signup.
2
עותק של הקוד: נכנסים ל-github.com/hilaf2331-rgb/translator ולוחצים Fork ואז Create fork. זה יוצר עותק של הקוד בחשבון שלך.
3
חשבון Cloudflare: נרשמים בחינם ב-dash.cloudflare.com/sign-up ומאשרים את המייל.
4
יצירת השרת: בתפריט של Cloudflare: Workers & Pages ← Create ← Start with Hello World!. בשם כותבים comic-helper ולוחצים Deploy. בשלב הזה השרת מציג "Hello World", וזה בסדר.
5
חיבור לקוד: בדף של השרת: Settings ← Build ← Connect ← GitHub. מאשרים גישה (עדיף לבחור Only select repositories ← translator), בוחרים את העותק שלך ואת הענף main, ולוחצים Connect.
6
הפעלת הבנייה: Cloudflare בונה את השרת כשמשהו משתנה בקוד. אם בלשונית Deployments לא מופיעה בנייה חדשה תוך כמה דקות: נכנסים לעותק שלך ב-GitHub, פותחים את הקובץ wrangler.jsonc, לוחצים על העיפרון ✏️, מוסיפים שורה ריקה בסוף ולוחצים Commit changes.
7
בדיקה: בדף הראשי של השרת ב-Cloudflare מופיעה הכתובת שלו, משהו כמו comic-helper.השם-שלך.workers.dev. פותחים אותה בספארי (עם https:// בהתחלה). צריך להופיע:
Comic Translator image helper is running ✓
אם עדיין כתוב "Hello World!", מחכים עוד דקה-שתיים ומרעננים.
8
חיבור למתרגם: באתר הקומיקס לוחצים ⚙, כותבים 4, מדביקים את הכתובת של השרת ולוחצים אישור. התמונות שנכשלו ינסו שוב לבד.
🔒 לא לפרסם את הכתובת של השרת (ולא לצלם את ⚙ ← 4 בסרטונים). כל מי שיודע אותה יכול להשתמש בשרת שלך.

שלב 8: כמה זה עולה

  • 💰 משלמים ל-Google לפי שימוש: לפי כמה תמונות מתורגמות. אין מנוי קבוע.
  • 📊 לראות כמה שילמת: console.cloud.google.com/billing ← Reports. בצד ימין מסננים Services ← Gemini API.
  • ⏳ החיוב מתעדכן באיחור של כמה שעות עד יום. מה שקראת היום יופיע מחר.
  • 🟢 לחסוך: ⚙ ← 7 (מצב חסכוני), בערך חצי מחיר. אם האיכות לא מספיקה, מכבים באותה דרך.
  • ♻️ תמונות שכבר תורגמו נשמרות, כך שחזרה לפרק לא עולה שוב.
  • ☁️ שרת העזר (אם צריך) חינמי.

שלב 10: פרטיות וחשוב לדעת

  • 🔒 המפתח נשמר רק באייפון שלך, באחסון הפרטי של Userscripts. הוא לא נשלח לאף אחד חוץ מ-Google, והאתרים שאת גולשת בהם לא יכולים לקרוא אותו.
  • 🖼️ התמונות נשלחות ל-Google לתרגום, כמו בכל שירות תרגום של תמונות.
  • 🚫 אם נראה שהמפתח דלף: מוחקים אותו ב-aistudio.google.com/apikey ויוצרים חדש. לוקח דקה.
  • 💻 במחשב: מתקינים את התוסף Tampermonkey (בכרום, באדג' או בפיירפוקס) ופותחים את אותו קישור משלב 4.
  • 📱 אנדרואיד: כרגע לא נתמך.
חשוב לדעת: המתרגם ניתן כמו שהוא, בחינם, בלי אחריות. כל אחד משתמש בו על אחריותו, משלם בעצמו ל-Google על השימוש שלו, ופועל לפי תנאי השימוש של Google ושל האתרים שהוא קורא בהם. הקוד פתוח לכולם, ברישיון MIT.
